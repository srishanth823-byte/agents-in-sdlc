現実的なシナリオ、完成したアプリケーション、共有バックログを使って、ソフトウェア開発ライフサイクル全体で GitHub Copilot を活用します。変更を段階的に計画、実装、テストし、プル リクエストをレビューして、agent と一緒に作業を管理します。

## シナリオ

あなたは、開発者向けのテーマを扱うボードゲーム クラウドファンディング企業 Tailspin Toys に入社したばかりの開発者です。チームのバックログは GitHub issue として登録されており、すぐに着手できます。filtering やページネーションなどの機能と、アクセシビリティやコーディング標準などの品質改善が含まれています。

## 環境を選ぶ

GitHub Copilot は、さまざまな作業環境で利用できます。作りたい方法に合った環境を選んでください。どのワークショップも、それぞれのセットアップから始まり、共通の Tailspin Toys シナリオを使います。

### [GitHub Copilot CLI][cli]

ターミナルでエージェント型アシスタントを使います。Plan と Autopilot の mode、instruction、skill、custom agent、Playwright MCP、Agent Merge、実用的な slash command を学びます。

### [GitHub Copilot app][app]

デスクトップ app で複数の agent session を並行して実行し、session mode を切り替え、canvas で共同作業して、GitHub issue とプル リクエストを管理します。

### [GitHub Copilot cloud agent][cloud]

GitHub issue を非同期 agent に割り当て、作業を導き、進捗を確認し、作成されたプル リクエストをレビューします。

### [Visual Studio Code][vscode]

Visual Studio Code と GitHub Codespaces で GitHub Copilot を使います。エディターを離れずに、Copilot Chat の agent mode、MCP server、custom agent を操作します。
